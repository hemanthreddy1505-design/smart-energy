# GridSense Enterprise EMS — Experimental & Simulation Datasets

This directory contains research-grade electrical time-series datasets, circuit metadata, Time-Of-Day (TOD) tariff structures, and benchmark anomaly catalogs generated by the **GridSense Enterprise EMS** simulation engine and virtual SCT-013 transducer array.

---

## 1. Datasets Overview

| File | Format | Records | Description |
|---|---|---|---|
| [`telemetry_sample_24h.csv`](./telemetry_sample_24h.csv) | CSV | 1,440 rows | Minute-by-minute diurnal load profile across 8 sub-circuits for 24 hours. |
| [`telemetry_sample_24h.json`](./telemetry_sample_24h.json) | JSON | 288 points + Summary | 5-minute sampled time-series with aggregate daily KPI statistics. |
| [`appliances_metadata.json`](./appliances_metadata.json) | JSON | 8 circuits | Complete transducer mapping, rated wattages, power factors, and DSM tiers. |
| [`tod_tariff_structure.json`](./tod_tariff_structure.json) | JSON | 2 DISCOMs | Time-of-Day tariff matrices (BESCOM LT-2, MSEDCL) & CEA carbon factors. |
| [`synthetic_anomalies.json`](./synthetic_anomalies.json) | JSON | 4 events | Labeled anomaly benchmark dataset for ML fault detection evaluation. |

## 2. Telemetry Schema & SI Units

The time-series CSV (`telemetry_sample_24h.csv`) follows the International Electrotechnical Commission (IEC 62053-21) metering standard conventions:

| Column | Type | Unit | Description |
|---|---|---|---|
| `timestamp` | ISO-8601 | UTC | Timestamp in format `YYYY-MM-DDTHH:MM:SSZ` |
| `mains_voltage_rms_v` | Float | Volts ($V_{\text{RMS}}$) | Mains supply voltage (nominal $230.0\text{ V} \pm 1.5\%$) |
| `mains_total_power_w` | Float | Watts ($W$) | Total instantaneous active power ($P = \sum P_i$) |
| `mains_current_rms_a` | Float | Amperes ($A_{\text{RMS}}$) | Aggregated line current calculated via $I = \frac{P}{V \cdot \text{PF}}$ |
| `mains_power_factor` | Float | Dimensionless | System aggregate displacement power factor ($\cos \phi$) |
| `frequency_hz` | Float | Hertz ($\text{Hz}$) | AC grid frequency (nominal $50.00\text{ Hz} \pm 0.05$) |
| `cumulative_energy_kwh` | Float | Kilowatt-hours ($\text{kWh}$) | Integrated active energy: $\int P(\tau) d\tau$ |
| `cumulative_cost_inr` | Float | INR ($₹$) | Piecewise TOD cost integration including peak surcharges |
| `ac_power_w` | Float | Watts ($W$) | CT-CH01: Air Conditioner (1.5 Ton Inverter) |
| `fridge_power_w` | Float | Watts ($W$) | CT-CH02: Refrigerator (Compressor run/idle cycles) |
| `tv_power_w` | Float | Watts ($W$) | CT-CH03: Smart Television (55" OLED display) |
| `pc_power_w` | Float | Watts ($W$) | CT-CH04: Workstation PC (Dual-display office load) |
| `lights_power_w` | Float | Watts ($W$) | CT-CH05: Living Room Lighting (Solid-state LED array) |
| `fan_power_w` | Float | Watts ($W$) | CT-CH06: Ceiling Fan (BLDC 3-speed motor) |
| `washing_machine_power_w`| Float | Watts ($W$) | CT-CH07: Washing Machine (Motor cycle + heater) |
| `geyser_power_w` | Float | Watts ($W$) | CT-CH08: Water Heater (Pure resistive 2.2 kW load) |

## 3. Python / Pandas Quick Analysis

You can load and analyze this dataset directly in Python:

```python
import pandas as pd
import matplotlib.pyplot as plt

# Load 24-hour diurnal profile
df = pd.read_csv('data/telemetry_sample_24h.csv', parse_dates=['timestamp'])

print(f"Total Daily Consumption: {df['cumulative_energy_kwh'].iloc[-1]:.2f} kWh")
print(f"Total Daily Cost: ₹{df['cumulative_cost_inr'].iloc[-1]:.2f}")
print(f"Peak Demand: {df['mains_total_power_w'].max():.1f} W")
print(f"Average Demand: {df['mains_total_power_w'].mean():.1f} W")

# Plot Diurnal Demand Curve
plt.figure(figsize=(12, 5))
plt.plot(df['timestamp'], df['mains_total_power_w'], label='Active Power (W)', color='#10b981')
plt.axvspan(df['timestamp'].iloc[1080], df['timestamp'].iloc[1320], color='orange', alpha=0.2, label='Peak Tariff (18:00-22:00)')
plt.ylabel('Power (Watts)')
plt.title('24-Hour Diurnal Residential Demand Curve')
plt.legend()
plt.grid(True, linestyle='--', alpha=0.6)
plt.savefig('docs/diurnal_curve_sample.png', dpi=300)
```

## 4. Anomaly Benchmark Classifications

The `synthetic_anomalies.json` dataset benchmarks automated fault detection across 4 categories:
1. `COMPRESSOR_LOCKED_ROTOR_STALL`: High current inrush without rotor rotation, resulting in low power factor ($\cos\phi < 0.72$) and thermal tripping risk.
2. `PEAK_TARIFF_COINCIDENCE_SURGE`: Heavy discretionary loads scheduled during the $1.25\times$ peak surcharge window (18:00–22:00).
3. `VAMPIRE_STANDBY_DRAIN`: Continuous parasitic idle consumption during nocturnal quiet hours (01:00–05:00).
4. `SANCTIONED_DEMAND_EXCEEDANCE`: Exceeding the grid contracted sanctioned demand limit (5,000 W).
