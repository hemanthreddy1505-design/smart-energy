# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 2.0.x | :white_check_mark: Active Support |
| 1.0.x | :x: End of Life |

## Reporting a Vulnerability

If you discover a security vulnerability in GridSense Enterprise EMS, please do **NOT** open a public issue. Instead, report it privately to the maintainers:
- **Email**: `dhnshydv@gmail.com` or through GitHub Private Vulnerability Reporting.
- Maintainers will respond within 48 hours with an initial assessment and timeline for a patch.
